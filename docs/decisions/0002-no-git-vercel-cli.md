# ADR 0002 — العمل بدون Git، والنشر على Vercel عبر CLI

- **الحالة:** معتمد من المالك (2026-10-15). **جزء Git مُستبدل** بـ[ADR 0011](0011-git-and-github.md) (2026-10-29)؛ جزء النشر عبر CLI قائم حتى المرحلة 9.
- **السياق:** المجلد ليس مستودع Git. عُرض على المالك إنشاء مستودع محلي فاختار عدم استخدامه.
- **القرار:**
  - لا يُنشأ مستودع Git، ولا تُنفذ أي أوامر Git.
  - النشر على Vercel يتم عبر `vercel deploy` من المجلد المحلي، بدل ربط مستودع.
  - النشر على VPS يتم برفع الملفات (rsync أو scp).
- **العواقب:**
  - لا سجل تغييرات تلقائي ولا تراجع سهل. التعويض:
    - توثيق دقيق في `docs/PROGRESS.md`.
    - توصية بأرشفة المجلد (zip) بعد كل مرحلة.
  - لا Preview Deployments تلقائية لكل تغيير.
  - يمكن إعادة النظر في هذا القرار في أي وقت دون أثر على الكود.
