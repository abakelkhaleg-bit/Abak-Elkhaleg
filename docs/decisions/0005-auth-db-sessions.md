# ADR 0005 — مصادقة الأدمن بجلسات في قاعدة البيانات

- **الحالة:** مقترح (يُعتمد مع الخطة)
- **السياق:**
  - حساب أدمن واحد، ولا تسجيل عام.
  - المطلوب:
    - تسجيل خروج **يبطل الجلسة فعليًا**.
    - rate limit.
    - Argon2id.
    - عمل على Vercel serverless وعلى VPS.
- **البدائل:**
  1. Auth.js (Credentials): مزود Credentials لا يدعم جلسات قاعدة البيانات افتراضيًا، فيفرض JWT. إبطال JWT عند الخروج يحتاج قائمة سوداء، فيعقّد الحالة دون فائدة لحساب واحد.
  2. iron-session (cookie مشفرة stateless): نفس مشكلة الإبطال.
  3. **جلسات في MongoDB، وهو المختار:** توكن عشوائي في كوكي HttpOnly، وhash له في `sessions` مع TTL.
- **القرار:** الخيار 3، ومعه:
  - Argon2id عبر `@node-rs/argon2`.
  - Rate limit في مجموعة `rate_limits` (TTL). تعمل في البيئتين دون Redis.
  - `requireAdmin()` إلزامي في كل نقطة دخول إدارية.
  - التفاصيل في [SECURITY.md](../SECURITY.md).
- **العواقب:**
  - كود مصادقة صغير نملكه بالكامل، ومغطى باختبارات A1–A10.
  - استعلام قاعدة بيانات لكل طلب إداري، وهذا مقبول.
