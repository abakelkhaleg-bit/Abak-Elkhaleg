# ADR 0008 — البحث العربي

- **الحالة:** مقترح (يُعتمد مع الخطة)
- **السياق:**
  - فهرس `$text` في MongoDB لا يدعم الاشتقاق العربي جيدًا، ولا يوحّد الهمزات والتاء المربوطة.
  - Atlas Search غير متاح في MongoDB الذاتية على VPS.
- **القرار:**
  - حقل `searchText` في Product يُحسب عند الحفظ من اسم المنتج والماركة والتصنيف، بعد `normalizeArabic()`. الدالة:
    - تحذف التشكيل (U+064B–U+0652) والتطويل (U+0640).
    - تحوّل أ/إ/آ/ٱ إلى ا، وى إلى ي، وة إلى ه، وؤ إلى و، وئ إلى ي.
    - تحوّل الأرقام العربية الهندية إلى لاتينية، وتحوّل الأحرف إلى lowercase، وتوحّد المسافات.
  - استعلام البحث يُطبَّع بنفس الدالة، ثم يُهرَّب، ثم يُطابَق كـregex على كل كلمة (AND)، مع فهرس و`limit`.
  - الاقتراحات: أول 6 نتائج منشورة، مع debounce 250ms، وحد أدنى حرفان.
  - البيانات الأصلية (`name` وغيره) لا تتغير.
  - عند تغيير اسم ماركة أو تصنيف يُعاد حساب `searchText` للمنتجات المرتبطة.
- **العواقب:** أداء كافٍ لكتالوج بالمئات أو بضعة آلاف. الترقية إلى Atlas Search ممكنة دون تغيير الواجهة.
