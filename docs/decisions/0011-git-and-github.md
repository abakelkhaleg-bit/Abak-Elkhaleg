# ADR 0011 — استخدام Git ومستودع GitHub

- **الحالة:** معتمد من المالك (2026-10-29). **يحل محل** [ADR 0002](0002-no-git-vercel-cli.md) في جزء Git.
- **السياق:** بعد المرحلة 6 طلب المالك رفع المشروع على GitHub، مع استثناء أي ملف فيه أسرار.
- **القرار:**
  - المشروع مستودع Git، والفرع الرئيسي `main`.
  - المستودع البعيد: `https://github.com/abakelkhaleg-bit/Abak-Elkhaleg.git`.
  - `.gitignore` يستثني:
    - كل ملفات `.env*` ما عدا `.env.example` (نموذج بلا قيم سرية).
    - ملفات المفاتيح (`*.pem`، `*.key`، `*.p12`) و`.vercel`.
    - مخرجات البناء والاختبار و`node_modules`.
  - قبل كل رفع: فحص الملفات المضافة بحثًا عن روابط MongoDB بكلمات مرور ومفاتيح Cloudinary والقيم العشوائية للأسرار.
  - الـcommit والـpush يتمان بطلب صريح من المالك فقط.
- **العواقب:**
  - سجل تغييرات وتراجع سهل، فلم تعد أرشفة المجلد (zip) بعد كل مرحلة ضرورية.
  - يمكن ربط Vercel بالمستودع لنشر تلقائي وPreview Deployments، أو الاستمرار بـVercel CLI. يُحسم في المرحلة 9.
  - إن كان المستودع عامًا فالكود ظاهر للجميع، لكن الأسرار ليست فيه. الأسرار في الإنتاج تُضبط في لوحة الاستضافة فقط.
  - أي سر يُرفع بالخطأ يُعتبر مكشوفًا: يُغيَّر فورًا من مصدره (Atlas أو Cloudinary)، ولا يكفي حذفه من المستودع.
